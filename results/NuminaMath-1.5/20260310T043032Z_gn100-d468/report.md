# Benchmark 報告 — NuminaMath-1.5 — 數學推理任務

> AIMO 競賽的內部驗證集，包含高難度數學題。特性：短輸入、長輸出（模型需進行多步推導）。

## 執行配置：10 個並發用戶，共執行 600 秒

### 摘要

本次 benchmark 以 **10 個並發用戶**持續執行 **600 秒**。
Dataset 中平均每個 prompt 含 **219 個 input token**，模型回覆平均 **7973 個 output token**。

- **TTFT（到第一個字的等待時間）**：平均 **3835.0ms**（P95: 3835.0ms） — 用戶送出 prompt 後等多久才開始看到回覆
- **TPOT（每個 output token 的生成時間）**：平均 **153.9ms**（P95: 153.9ms） — 體感約 6 tok/s 的生成速度
- **ITL（Token 間延遲）**：平均 **153.5ms**（P95: 153.5ms）
- **E2E 延遲**：平均 **1227.41s**（P95: 1227.41s） — 從送出 prompt 到收到完整回覆的總時間
- **Token Throughput**：output **6.5 tok/s**，total **6.7 tok/s**
- **Request Throughput**：**0.000 req/s**
- **平均活躍用戶數**：**1.0** / 10
