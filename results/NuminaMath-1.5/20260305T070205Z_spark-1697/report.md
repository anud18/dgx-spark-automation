### 摘要

本次 benchmark 以 **10 個並發用戶**持續執行 **60 秒**。
Dataset 中平均每個 prompt 含 **134 個 input token**，模型回覆平均 **5614 個 output token**。

- **TTFT（到第一個字的等待時間）**：平均 **77.6ms**（P95: 77.6ms）— 用戶送出 prompt 後等多久才開始看到回覆
- **TPOT（每個 output token 的生成時間）**：平均 **44.9ms**（P95: 44.9ms）— 體感約 22 tok/s 的生成速度
- **ITL（Token 間延遲）**：平均 **44.8ms**（P95: 44.8ms）
- **E2E 延遲**：平均 **251.86s**（P95: 251.86s）— 從送出 prompt 到收到完整回覆的總時間
- **Token Throughput**：output **22.3 tok/s**，total **22.8 tok/s**
- **Request Throughput**：**0.000 req/s**
- **平均活躍用戶數**：**1.0** / 10
