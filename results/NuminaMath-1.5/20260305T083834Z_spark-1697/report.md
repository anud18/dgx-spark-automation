# Benchmark 報告 — NuminaMath-1.5 — 數學推理任務

> AIMO 競賽的內部驗證集，包含高難度數學題。特性：短輸入、長輸出（模型需進行多步推導）。

> **實驗備註：** vLLM 0.15.0

## 執行配置：10 個並發用戶，共執行 600 秒

### 摘要

本次 benchmark 以 **10 個並發用戶**持續執行 **600 秒**。
Dataset 中平均每個 prompt 含 **129 個 input token**，模型回覆平均 **5421 個 output token**。

- **TTFT（到第一個字的等待時間）**：平均 **297.9ms**（P95: 391.5ms） — 用戶送出 prompt 後等多久才開始看到回覆
- **TPOT（每個 output token 的生成時間）**：平均 **86.5ms**（P95: 92.6ms） — 體感約 12 tok/s 的生成速度
- **ITL（Token 間延遲）**：平均 **86.5ms**（P95: 92.6ms）
- **E2E 延遲**：平均 **469.20s**（P95: 609.22s） — 從送出 prompt 到收到完整回覆的總時間
- **Token Throughput**：output **142.4 tok/s**，total **145.8 tok/s**
- **Request Throughput**：**0.025 req/s**
- **平均活躍用戶數**：**12.5** / 10
