# Benchmark 報告 — InstructCoder — Coding 任務

> InstructCoder 是第一個專為 LLM 設計的程式碼編輯 dataset，涵蓋各種程式修改與生成任務。

## 執行配置：10 個並發用戶，共執行 60 秒

### 摘要

本次 benchmark 以 **10 個並發用戶**持續執行 **60 秒**。
Dataset 中平均每個 prompt 含 **120 個 input token**，模型回覆平均 **540 個 output token**。

- **TTFT（到第一個字的等待時間）**：平均 **79.5ms**（P95: 92.8ms）— 用戶送出 prompt 後等多久才開始看到回覆
- **TPOT（每個 output token 的生成時間）**：平均 **27.7ms**（P95: 28.7ms）— 體感約 36 tok/s 的生成速度
- **ITL（Token 間延遲）**：平均 **27.6ms**（P95: 28.6ms）
- **E2E 延遲**：平均 **14.99s**（P95: 30.37s）— 從送出 prompt 到收到完整回覆的總時間
- **Token Throughput**：output **278.0 tok/s**，total **339.8 tok/s**
- **Request Throughput**：**0.517 req/s**
- **平均活躍用戶數**：**8.0** / 10
