# Benchmark 報告 — InstructCoder — Coding 任務

> InstructCoder 是第一個專為 LLM 設計的程式碼編輯 dataset，涵蓋各種程式修改與生成任務。

> **實驗備註：** vLLM 0.15.0

## 執行配置：10 個並發用戶，共執行 600 秒

### 摘要

本次 benchmark 以 **10 個並發用戶**持續執行 **600 秒**。
Dataset 中平均每個 prompt 含 **140 個 input token**，模型回覆平均 **676 個 output token**。

- **TTFT（到第一個字的等待時間）**：平均 **150.4ms**（P95: 185.5ms）— 用戶送出 prompt 後等多久才開始看到回覆
- **TPOT（每個 output token 的生成時間）**：平均 **44.9ms**（P95: 46.4ms）— 體感約 22 tok/s 的生成速度
- **ITL（Token 間延遲）**：平均 **44.7ms**（P95: 46.2ms）
- **E2E 延遲**：平均 **30.35s**（P95: 63.46s）— 從送出 prompt 到收到完整回覆的總時間
- **Token Throughput**：output **683.3 tok/s**，total **824.9 tok/s**
- **Request Throughput**：**1.013 req/s**
- **平均活躍用戶數**：**30.8** / 10
