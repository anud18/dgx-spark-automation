### 摘要

本次 benchmark 以 **10 個並發用戶**持續執行 **60 秒**。
Dataset 中平均每個 prompt 含 **20 個 input token**，模型回覆平均 **535 個 output token**。

- **TTFT（到第一個字的等待時間）**：平均 **73.3ms**（P95: 85.7ms）— 用戶送出 prompt 後等多久才開始看到回覆
- **TPOT（每個 output token 的生成時間）**：平均 **27.1ms**（P95: 28.4ms）— 體感約 37 tok/s 的生成速度
- **ITL（Token 間延遲）**：平均 **27.0ms**（P95: 28.3ms）
- **E2E 延遲**：平均 **14.54s**（P95: 33.88s）— 從送出 prompt 到收到完整回覆的總時間
- **Token Throughput**：output **280.8 tok/s**，total **291.1 tok/s**
- **Request Throughput**：**0.533 req/s**
- **平均活躍用戶數**：**7.9** / 10
