### 摘要

本次 benchmark 以 **10 個並發用戶**持續執行 **600 秒**。
Dataset 中平均每個 prompt 含 **30 個 input token**，模型回覆平均 **640 個 output token**。

- **TTFT（到第一個字的等待時間）**：平均 **144.5ms**（P95: 176.2ms）— 用戶送出 prompt 後等多久才開始看到回覆
- **TPOT（每個 output token 的生成時間）**：平均 **47.7ms**（P95: 56.9ms）— 體感約 21 tok/s 的生成速度
- **ITL（Token 間延遲）**：平均 **47.6ms**（P95: 56.1ms）
- **E2E 延遲**：平均 **30.61s**（P95: 86.20s）— 從送出 prompt 到收到完整回覆的總時間
- **Token Throughput**：output **604.6 tok/s**，total **632.8 tok/s**
- **Request Throughput**：**0.943 req/s**
- **平均活躍用戶數**：**28.9** / 10
