### 摘要

本次 benchmark 以 **10 個並發用戶**持續執行 **600 秒**。
Dataset 中平均每個 prompt 含 **28 個 input token**，模型回覆平均 **1400 個 output token**。

- **TTFT（到第一個字的等待時間）**：平均 **170.9ms**（P95: 190.9ms）— 用戶送出 prompt 後等多久才開始看到回覆
- **TPOT（每個 output token 的生成時間）**：平均 **76.8ms**（P95: 81.7ms）— 體感約 13 tok/s 的生成速度
- **ITL（Token 間延遲）**：平均 **76.7ms**（P95: 81.6ms）
- **E2E 延遲**：平均 **107.52s**（P95: 248.37s）— 從送出 prompt 到收到完整回覆的總時間
- **Token Throughput**：output **388.1 tok/s**，total **396.0 tok/s**
- **Request Throughput**：**0.277 req/s**
- **平均活躍用戶數**：**29.9** / 10
