> 真實使用者與 AI 的對話紀錄（ShareGPT_Vicuna_unfiltered），涵蓋各種日常問答與指令場景。

### 摘要

本次 benchmark 以 **10 個並發用戶**持續執行 **60 秒**。
Dataset 中平均每個 prompt 含 **20 個 input token**，模型回覆平均 **413 個 output token**。

- **TTFT（到第一個字的等待時間）**：平均 **130.7ms**（P95: 143.6ms）— 用戶送出 prompt 後等多久才開始看到回覆
- **TPOT（每個 output token 的生成時間）**：平均 **47.0ms**（P95: 48.4ms）— 體感約 21 tok/s 的生成速度
- **ITL（Token 間延遲）**：平均 **46.8ms**（P95: 48.1ms）
- **E2E 延遲**：平均 **19.47s**（P95: 47.39s）— 從送出 prompt 到收到完整回覆的總時間
- **Token Throughput**：output **143.8 tok/s**，total **150.9 tok/s**
- **Request Throughput**：**0.333 req/s**
- **平均活躍用戶數**：**6.8** / 10
