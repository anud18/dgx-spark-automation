### 摘要

本次 benchmark 以 **10 個並發用戶**持續執行 **60 秒**。
Dataset 中平均每個 prompt 含 **20 個 input token**，模型回覆平均 **480 個 output token**。

- **TTFT（到第一個字的等待時間）**：平均 **73.9ms**（P95: 84.6ms）— 用戶送出 prompt 後等多久才開始看到回覆
- **TPOT（每個 output token 的生成時間）**：平均 **27.2ms**（P95: 29.3ms）— 體感約 37 tok/s 的生成速度
- **ITL（Token 間延遲）**：平均 **27.1ms**（P95: 29.2ms）
- **E2E 延遲**：平均 **13.09s**（P95: 27.61s）— 從送出 prompt 到收到完整回覆的總時間
- **Token Throughput**：output **246.2 tok/s**，total **256.5 tok/s**
- **Request Throughput**：**0.500 req/s**
- **平均活躍用戶數**：**6.8** / 10
