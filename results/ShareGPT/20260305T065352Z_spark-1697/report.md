### 摘要

本次 benchmark 以 **10 個並發用戶**持續執行 **6 秒**。
Dataset 中平均每個 prompt 含 **17 個 input token**，模型回覆平均 **140 個 output token**。

- **TTFT（到第一個字的等待時間）**：平均 **62.1ms**（P95: 73.9ms）— 用戶送出 prompt 後等多久才開始看到回覆
- **TPOT（每個 output token 的生成時間）**：平均 **24.9ms**（P95: 25.3ms）— 體感約 40 tok/s 的生成速度
- **ITL（Token 間延遲）**：平均 **24.6ms**（P95: 25.1ms）
- **E2E 延遲**：平均 **3.50s**（P95: 5.97s）— 從送出 prompt 到收到完整回覆的總時間
- **Token Throughput**：output **121.0 tok/s**，total **135.5 tok/s**
- **Request Throughput**：**1.000 req/s**
- **平均活躍用戶數**：**3.7** / 10
