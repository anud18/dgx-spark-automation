# Benchmark 報告 — CNN / DailyMail — 新聞摘要

> CNN 與 Daily Mail 共 30 萬篇新聞文章的摘要任務。特性：長輸入、短輸出（Summarization）。

## 執行配置：10 個並發用戶，共執行 60 秒

### 效能評分

**Goodput: 84.8%**（28 / 33 requests 同時滿足 TTFT<=500ms, TPOT<=50ms, ITL<=50ms）

### 摘要

本次 benchmark 以 **10 個並發用戶**持續執行 **60 秒**。
Dataset 中平均每個 prompt 含 **610 個 input token**，模型回覆平均 **626 個 output token**。

- **TTFT（到第一個字的等待時間）**：平均 **261.3ms**（P95: 682.9ms）— 用戶送出 prompt 後等多久才開始看到回覆
- **TPOT（每個 output token 的生成時間）**：平均 **32.3ms**（P95: 32.6ms）— 體感約 31 tok/s 的生成速度
- **ITL（Token 間延遲）**：平均 **32.0ms**（P95: 32.4ms）
- **E2E 延遲**：平均 **20.28s**（P95: 36.39s）— 從送出 prompt 到收到完整回覆的總時間
- **Token Throughput**：output **235.2 tok/s**，total **464.4 tok/s**
- **Request Throughput**：**0.367 req/s**
- **平均活躍用戶數**：**7.8** / 10
