# Benchmark 報告 — CNN / DailyMail — 新聞摘要

> CNN 與 Daily Mail 共 30 萬篇新聞文章的摘要任務。特性：長輸入、短輸出（Summarization）。

## 執行配置：10 個並發用戶，共執行 600 秒

### 摘要

本次 benchmark 以 **10 個並發用戶**持續執行 **600 秒**。
Dataset 中平均每個 prompt 含 **806 個 input token**，模型回覆平均 **1277 個 output token**。

- **TTFT（到第一個字的等待時間）**：平均 **613.2ms**（P95: 2635.2ms） — 用戶送出 prompt 後等多久才開始看到回覆
- **TPOT（每個 output token 的生成時間）**：平均 **88.6ms**（P95: 92.2ms） — 體感約 11 tok/s 的生成速度
- **ITL（Token 間延遲）**：平均 **88.2ms**（P95: 92.1ms）
- **E2E 延遲**：平均 **113.29s**（P95: 163.89s） — 從送出 prompt 到收到完整回覆的總時間
- **Token Throughput**：output **325.5 tok/s**，total **531.0 tok/s**
- **Request Throughput**：**0.253 req/s**
- **平均活躍用戶數**：**28.9** / 10
