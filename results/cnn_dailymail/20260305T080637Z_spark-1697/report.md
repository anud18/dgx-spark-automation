### 摘要

本次 benchmark 以 **10 個並發用戶**持續執行 **600 秒**。
Dataset 中平均每個 prompt 含 **761 個 input token**，模型回覆平均 **797 個 output token**。

- **TTFT（到第一個字的等待時間）**：平均 **321.0ms**（P95: 994.1ms）— 用戶送出 prompt 後等多久才開始看到回覆
- **TPOT（每個 output token 的生成時間）**：平均 **60.6ms**（P95: 63.0ms）— 體感約 16 tok/s 的生成速度
- **ITL（Token 間延遲）**：平均 **60.3ms**（P95: 62.6ms）
- **E2E 延遲**：平均 **48.40s**（P95: 74.81s）— 從送出 prompt 到收到完整回覆的總時間
- **Token Throughput**：output **499.8 tok/s**，total **976.9 tok/s**
- **Request Throughput**：**0.628 req/s**
- **平均活躍用戶數**：**30.5** / 10
